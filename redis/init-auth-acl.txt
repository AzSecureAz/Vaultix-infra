# ====================================================================
# Provisioning script for Authorization Service Redis ACL User
# ====================================================================
# INSTRUCTIONS:
# Execute in Redis Commander (via the CLI console at the bottom) or redis-cli:
#
# 1. Create dedicated user restricted to 'auth:*' keys and Pub/Sub channels:
ACL SETUSER auth_user on >auth_password ~auth:* &* +@all

# 2. Persist the user to /data/users.acl (survives restarts):
ACL SAVE
# ====================================================================
